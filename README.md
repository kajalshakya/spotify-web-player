# Spotify Clone

A Spotify-inspired music player built using HTML, CSS, and JavaScript. This project recreates the look and feel of Spotify's web player with a dark theme, sidebar navigation, music cards, and a bottom music player with functional audio controls.

## Features

- Sidebar navigation with Home, Search, and Your Library sections.
- Playlist creation and podcast discovery sections.
- Recently played music cards.
- Trending songs with titles and artist names.
- Featured music charts for Global and India playlists.
- Bottom music player with album artwork, song title, and artist information.
- Play and pause functionality.
- Next and previous song controls.
- Shuffle mode to play songs in random order.
- Repeat mode to replay the current song.
- Interactive progress bar with current time and total duration.
- Volume control.
- Song selection by clicking music cards.
- Dark theme with hover effects.
- Custom typography using Google Fonts.
- Icons using Font Awesome.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome
- HTML5 Audio API

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, run the project using the Live Server extension in VS Code.

No backend setup or additional installation is required.
