# Spotify Clone UI

A Spotify-inspired music player user interface built using HTML5 and CSS3. This project recreates the look and feel of Spotify's web player with a dark theme, sidebar navigation, music cards, and a bottom music player layout.

## Features

- Sidebar navigation with Home, Search, and Your Library sections.
- Playlist creation and podcast discovery sections.
- Recently played music cards.
- Trending songs with titles and artist names.
- Featured music charts for Global and India playlists.
- Bottom music player layout with album artwork and song information.
- Playback control icons and progress bars.
- Dark theme with hover effects.
- Custom typography using Google Fonts.
- Icons using Font Awesome.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.

No backend setup or additional installation is required.
